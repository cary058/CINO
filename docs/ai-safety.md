# Архитектура безопасности ИИ (AI Safety Layer)

## 1. Пайплайн обработки сообщений
```
Сообщение пользователя
       ↓
Классификатор безопасности (analyzeMessageSafety)
       ↓
Проверка на кризис / паранойю / циклы заверений
       ↓
Выбор режима (LISTENING, REFLECTION, ADVICE, CASUAL_SUPPORT)
       ↓
Генерация безопасного ответа (AI Provider Abstraction)
       ↓
Фильтрация и логирование инцидента безопасности (при необходимости)
       ↓
Выдача ответа пользователю
```

## 2. Категории и уровни риска
- **Категории**: `SUICIDE`, `SELF_HARM`, `VIOLENCE`, `ABUSE`, `PSYCHOSIS_OR_PARANOIA`, `PANIC`, `ANXIETY`, `GENERAL_DISTRESS`, `NONE`.
- **Уровни риска**: `NONE`, `LOW`, `MODERATE`, `HIGH`, `CRITICAL`.

## 3. Критические правила
1. **Эмоцию можно валидировать, непроверенный факт нельзя подтверждать**:
   - ИИ никогда не подтверждает параноидальные утверждения («да, за тобой следят спецслужбы»).
   - Вместо этого валидируется страх («понимаю, как тревожно с этим чувством») и предлагается заземление.
2. **Предотвращение цикла бесконечных заверений (Reassurance Loop)**:
   - При многократных вопросах «точно я не умру?» или «поклянись, что всё будет хорошо» ИИ мягко объясняет невозможность 100% гарантий и помогает справиться со страхом неопределенности.
3. **Кризисный протокол**:
   - При высоком риске активируется баннер экстренных служб с номером 112 (Казахстан) и горячей линией доверия 150/111.
