# Жизненный цикл направляющего (Coordinator Workflow)

1. **Мониторинг очереди обращений**:
   - В диспетчерской `/coordinator` отображаются поступающие запросы с метками срочности, категорией и ожиданием.

2. **Первичный контакт и триаж**:
   - Координатор открывает обращение, знакомится с описанием пользователя и может отправить уточняющее сообщение.

3. **Маршрутизация**:
   - Назначение свободного волонтёра (система фильтрует только `APPROVED` и `AVAILABLE` специалистов, у которых не превышен лимит 2 диалогов).
   - Назначение верифицированного психолога для сложных терапевтических запросов.

4. **Внутренние служебные заметки**:
   - Ведение конфиденциальных заметок по обращению, доступных только коллегам и администраторам, с логированием в журнал аудита.
