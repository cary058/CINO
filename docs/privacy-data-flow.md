# Потоки данных и конфиденциальность (Privacy Data Flow)

```
[ Пользователь в браузере ]
           ↓ (HTTPS / TLS 1.3)
[ Next.js Сервер Приложения ] (Псевдонимизация: ID SINO-XXXXXX)
           ↓ (Внутренняя сеть)
[ База данных PostgreSQL (Регион Казахстан) ]
           ↓
[ Адаптер ИИ (Защищённый запрос без логов на сервере провайдера) ]
```

## Принципы работы с чувствительными данными:
1. **Никаких секретов на клиенте**: `AI_API_KEY`, токены базы данных и сессионные ключи никогда не передаются в браузер.
2. **Изоляция памяти диалогов**: Память ИИ изолирована в рамках одного активного диалога.
3. **Право на забвение**: Возможность полного удаления профиля и истории диалогов пользователем в один клик.
4. **Хранение логов**: IP-адреса хешируются (`SHA-256`) перед записью в журнал аудита.
