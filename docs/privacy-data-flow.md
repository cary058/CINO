# Потоки данных демо-СИНО

```text
[Пользователь]
    │ HTTPS
    ▼
[Сервер СИНО на Render, Франкфурт]
    ├──► [PostgreSQL демо-проекта на Render, Франкфурт]
    └──► [Настроенный ИИ-провайдер, если подключён]
          Gemini API получает сообщение и последние сообщения диалога
```

## Ограничения демо

- Эта версия использует вымышленные аккаунты и истории. Не вводите реальные имена, контакты, адреса или чувствительные сведения.
- Сервер и база данных демо находятся во Франкфурте, Германия. Локализация базы в Казахстане не настроена.
- При подключении Gemini текст сообщения и часть истории отправляются в Gemini API для формирования ответа. Для бесплатного тарифа Google указывает, что содержание может использоваться для улучшения продуктов. Не используйте бесплатный тариф для переписки реальных клиентов.
- Для платного тарифа условия использования данных отличаются; их нужно отдельно проверить и отразить в политике до запуска сервиса для реальных людей.
- API-ключ передаётся только с сервера в заголовке запроса и не отправляется в браузер.

## Технические меры

1. Ключи ИИ, базы данных и сессий не передаются клиенту.
2. Контекст для ответа ограничен последними сообщениями одного диалога.
3. Передача между браузером и сервером происходит по HTTPS.
4. Этот документ описывает демо-конфигурацию и не является подтверждением соответствия требованиям для производственного сервиса.
