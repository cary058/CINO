# Публичная демо-версия СИНО

Демо разворачивает полноценное приложение Next.js на бесплатном Render Free и использует бесплатную базу Neon PostgreSQL. Render располагается во Франкфурте; в Neon при создании базы выберите регион Frankfurt (`eu-central-1`).

## Важно

- Это только общедоступная демонстрация. Не вводите настоящие имена, адреса, телефоны, сведения о здоровье или реальные истории.
- У демо общий набор тестовых ролей и пароль `Password123!`; любой посетитель может войти в эти тестовые аккаунты.
- Бесплатный Render засыпает после 15 минут без запросов, поэтому первое открытие может занять около минуты. Файловая система временная, поэтому база размещена отдельно.
- Бесплатный Neon имеет лимиты и не заменяет резервные копии. При превышении месячных лимитов база может временно остановиться.
- Не используйте эту зарубежную демо-среду для реальных клиентских обращений.

## Первичная настройка

1. Создайте бесплатный проект PostgreSQL в Neon и выберите Frankfurt (`eu-central-1`).
2. Скопируйте pooled connection string Neon. Он понадобится как секрет `DATABASE_URL`.
3. В Render выберите создание нового Blueprint из GitHub-репозитория `cary058/CINO` и ветки, где находится этот файл `render.yaml`.
4. При настройке Blueprint вставьте `DATABASE_URL`. Render автоматически создаст случайный `SESSION_SECRET`.
5. Дождитесь первого успешного Deploy. На старте приложение подготовит PostgreSQL и добавит вымышленные тестовые аккаунты.

## Подключение Telegram-бота

Бот добавлен как часть сайта. Он создаёт вымышленную запись пользователя после подтверждения правил, отвечает встроенным демонстрационным ИИ и отправляет запросы живой поддержки в `/coordinator`. Ответ координатора из сайта возвращается человеку в Telegram.

1. В Telegram откройте `@BotFather`, отправьте `/newbot` и задайте имя и адрес бота. BotFather выдаст токен. Никому не отправляйте его и не вставляйте в этот чат.
2. В Render откройте сервис `sino-demo` → **Environment**. Добавьте `TELEGRAM_BOT_TOKEN` (токен от BotFather) и `TELEGRAM_WEBHOOK_SECRET` (случайная строка из латинских букв, цифр, `_` и `-`, длиной 32–64 знака). Сохраните изменения и дождитесь перезапуска.
3. В папке проекта откройте файл `.env` только на своём компьютере, задайте те же две переменные, а также `APP_URL` — полный адрес сайта Render.
4. В терминале из папки проекта выполните `npm run telegram:set-webhook`. Скрипт подключит защищённый адрес для получения сообщений ботом.
5. Откройте ссылку бота из BotFather и нажмите **Start**. В демо используйте только вымышленные сообщения.

Токен бота — как пароль: храните его только в секретных переменных Render и локальном `.env`, не публикуйте и не добавляйте в GitHub.

Тестовые аккаунты и общий пароль показываются на странице входа только при включённом `NEXT_PUBLIC_DEMO_MODE`.
