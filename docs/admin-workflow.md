# Руководство администратора (Admin Workflow)

1. **Первичный запуск (Bootstrap)**:
   - При первом запуске аккаунт `admin@sino.kz` наделен ролью `SUPER_ADMIN`.
   - Вход в панель управления осуществляется по адресу `/admin`.

2. **Мониторинг метрик**:
   - Отслеживание нагрузки: активные диалоги ИИ, обращения в очереди, доступные волонтёры и психологи.

3. **Управление доступом и персоналом**:
   - Одобрение заявок волонтёров после проверки результатов тестов.
   - Верификация дипломов и сертификатов психологов.
   - Создание одноразовых инвайт-ссылок для новых сотрудников.

4. **Безопасность и аварийные переключатели**:
   - Просмотр инцидентов безопасности (`Safety Events`).
   - Модерация жалоб (`Reports`) с возможностью предупреждения или блокировки пользователя.
   - Аварийное отключение ИИ или живого чата с помощью Kill Switch.
