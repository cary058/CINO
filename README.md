# СИНО — «слушаем и не осуждаем»

> Полноценная production-ready платформа бережной эмоциональной поддержки с искусственным интеллектом, направляющими координаторами, волонтёрами и проверенными психологами.

---

## 🌟 О проекте

**СИНО** — это бесплатный сервис эмоциональной поддержки, где человек может анонимно выговориться в чате с ИИ, а при необходимости запросить поддержку подготовленного волонтёра или проверенного психолога.

### Ключевые возможности:
1. **AI-чат с Safety Layer**:
   - Чат с ИИ на базе принципов активного слушания.
   - 4 режима диалога: `Слушание`, `Осмысление`, `Совет`, `Теплая беседа`.
   - Автоматическая оценка уровня риска (`NONE`, `LOW`, `MODERATE`, `HIGH`, `CRITICAL`) и кризисный протокол с номерами экстренных служб (112 Казахстан, 150, 111).
   - Защита от деструктивных циклов заверений и неподтверждение бредовых идей как фактов.
2. **Диспетчерская направляющего (Coordinator Triaging Desk)**:
   - Очередь обращений живых пользователей в реальном времени.
   - Интеллектуальное распределение между волонтёрами и психологами.
   - Конфиденциальные служебные заметки с аудитом доступа.
3. **Волонтёрская программа и интерактивное обучение**:
   - Публичная анкета кандидата на `/volunteer/apply`.
   - Обязательный интерактивный курс из 10 модулей с проверочными тестами на `/volunteer/training`.
   - Кабинет волонтёра с контролем нагрузки (макс. 2 диалога) и статусами доступности.
4. **Кабинет верифицированного психолога**:
   - Верификация дипломов и квалификаций.
   - Официальный бейдж специалиста в чате с клиентом.
5. **Административная панель и безопасность**:
   - Аналитика метрик платформы в реальном времени.
   - Ролевая модель доступа (`RBAC`), неизменяемый `Audit Log`, журнал безопасности `Safety Events`.
   - Модерация жалоб с возможностью предупреждения и блокировки.
   - Аварийные переключатели (**Kill Switches**) для мгновенного отключения ИИ или живого чата.
6. **Дизайн и атмосфера**:
   - Глубокий ночной сине-голубой фон со звёздным небом и сияющими акцентами.
   - Полупрозрачные Glassmorphism-панели с мягким размытием.
   - Фирменный символ и аватар — **Ухо** (Слушаем и не осуждаем).
   - Переключатель тем: «Ночь ▼», «День», «Системная».

## 🛠 Технологический стек

- **Frontend**: Next.js 14/15 (App Router), React 18/19, TypeScript, Tailwind CSS, Lucide Icons.
- **Backend**: Next.js API Routes, Server Actions, Node.js.
- **База данных**: PostgreSQL (Production) / SQLite (Development) через Prisma ORM.
- **Аутентификация**: Сессии на криптографических JWT (`jose`), пароли `bcrypt` / `Argon2id`.
- **Безопасность**: Защита от IDOR, XSS, CSRF, Rate Limiting, псевдонимные публичные идентификаторы (`SINO-8F42A1`).
- **Realtime**: Server-Sent Events (SSE) + Event Bus.
- **ИИ-провайдеры**: Абстракция `AIProvider` (Встроенный офлайн эмпатичный движок `mock`, Google Gemini API, OpenAI API).

## 🚀 Быстрый старт (Локальная разработка)

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

### 3. Инициализация базы данных и сид тестовых данных
```bash
# Генерация Prisma клиента и создание таблиц
npm run prisma:push

# Заполнение тестовыми аккаунтами и 10 модулями обучения
npm run prisma:seed
```

### 4. Запуск приложения
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🤖 Конфигурация ИИ-провайдера

Сервис не привязан жестко к одному провайдеру. Переключение осуществляется в `.env`:
```env
# 1. Встроенный эмпатичный движок (не требует API-ключей, работает офлайн)
AI_PROVIDER=mock

# 2. Google Gemini API
AI_PROVIDER=gemini
AI_API_KEY=your_gemini_api_key_here
AI_MODEL=gemini-3.8-flash

# 3. OpenAI API
AI_PROVIDER=openai
AI_API_KEY=your_openai_api_key_here
AI_MODEL=gpt-4o-mini
```
